# Archived Content

This folder contains preserved Sunder & Co. Insights, Blog, and Case Study content that has been removed from the public-facing website.

The `unready-pages` folder preserves disabled Advisory, Technology, and engagement page sources that are intentionally excluded from the launch build.

Do not delete these files. They are intentionally archived so they can be restored, rewritten, or reused later.

Large geometry assets that exceed normal GitHub file-size limits may be stored as restorable `.gz` files in this archive.

Current public behavior:
- Not shown in navigation
- Not shown on homepage
- Not shown in footer
- Not included in public content previews
- Excluded from sitemap/feed/search indexing where applicable

Do NOT delete:
- Blog MDX, markdown, JSON, or CMS content files
- Insight MDX, markdown, JSON, or CMS content files
- Case study MDX, markdown, JSON, or CMS content files
- Related images/assets unless they are safely moved into the archive
- Reusable components that may be restored later
- Global SEO metadata systems
- Structured data utilities globally
- Sitemap/feed utilities globally unless they need a narrow exclusion for archived content
- Service pages
- Main pages unrelated to Blogs, Insights, or Case Studies
- 3D hero files
- Typography files
- Animation systems
- Global layout/design system files unless absolutely necessary
